# Case studies

These pages check real open-source projects on the platforms their build configuration names. Each study pins the project's revision and wheelgap version, records the target assumptions and commands, and explains the gaps and possible next steps. Results describe the package files available when the check ran; new uploads and lockfile updates can change them.
